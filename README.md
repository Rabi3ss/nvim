# plugins

- algha : customizable startup dashboard for quick access to recent files and shortcuts.
- catppuccin : An eye-friendly color theme that enhances the visual layout of your editor and code.
- lualine : bottom status bar that shows key info like your current file, Git branch, and errors.
- neo-tree : sidebar file explorer for easily navigating, creating, and managing project files.
- telescope : fast search tool to instantly find files and text across your project with live previews.
- tresitter : code parsing engine that provides accurate, intelligent syntax highlighting.
- cord : It connects Neovim to your Discord desktop application to display your current coding activity on your Discord profile status.
